3. TYPE FLOORS & LINUX DEJAVU FONT-SAFETY RULES (HARD BUILD GATE)
------------------------------------------------------------------------------
Type Floors (enforced by load_font() + runtime asserts):
  - Masthead date:       56px native / 56px DejaVu stress (>= 48px, largest text)
  - Hero headline:       22px Bold Serif (sentence case)
  - Medium headline:     15px Bold Serif (sentence case)
  - Index headline:      13px Bold Sans
  - Index fact:          11px Regular Sans
  - Body / labels:       >= 10px everywhere outside footer meta
  - Footer meta only:    9px (legend, sources, 23 left-outs)

Linux Font Priority & DejaVu Safety Gate:
  - Font search prefers Liberation Serif/Sans before DejaVu Serif/Sans on Linux,
    AND every invocation of draw.py runs a mandatory full-page render under
    DEJAVU_STRESS_PROFILE (DejaVu if installed, else Verdana + 1.14x Georgia
    Serif width multiplier on Windows, simulating +14%..+19% wider Linux glyphs).
  - wrap_strict() RAISES AssertionError if any word is dropped, any token
    exceeds max_w, any "..." or "…" ellipsis appears, or line count > max_lines.
  - TextAuditor tracks the exact bounding box of every audited text element and
    RAISES AssertionError on any container overflow (horizontal or vertical) or
    any text-vs-text bounding-box collision.
  - render_clipped_scene() renders every hero and medium illustration into its
    own isolated offscreen RGB buffer before pasting so vector geometry can
    never bleed across card typography.
  - CLI support: `python draw.py --dejavu-test <path.png>` writes the stress
    render for direct 1024px visual verification alongside `entry.png`.
